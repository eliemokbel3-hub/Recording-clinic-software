# Project: Privacy-First Cliniko Clinical Scribe

## What This App Does
A single-practitioner clinical scribe for two Cliniko clinics: a thin Chrome extension embedded in the Cliniko workflow plus a secure Windows desktop companion that records consultations, runs local Whisper transcription and local note generation (a template-mapped clinical note, with optional prose writing styles from the local Qwen3-4B-Instruct-2507 language model), and creates draft treatment notes through Cliniko's official API. No cloud processing of audio or transcripts; the clinician reviews and finalises every note in Cliniko. See `PLAN.md` for the full product plan.

## Database Notes
No database server: every store is files under `%LOCALAPPDATA%\ClinikoScribe`, each DPAPI-keyed for this Windows login. Since the installation plan that is the INSTALLED app's folder; a source checkout (the developer build) keeps the same stores, plus its models, under `%LOCALAPPDATA%\ClinikoScribe-dev` and never touches the production folder except the shared single-instance `app.lock` and the one-time migration `register-native-host.py --unregister`, which removes the old per-user registration's two files there (`install_layout.py`; plan C8).
- `sessions\<id>\` — one live or recoverable recording (`key.dpapi`, `encounter.enc`, `audio.enc`, transcript, `note.enc`, `generated.enc`, `saved-provenance.enc`, `write.enc`); removed at Complete or Discard, swept after 24 h.
- `audit\YYYY-MM\<id>.enc` — one content-free row per session under one store key, kept 7 years, exportable as CSV (`audit.py`).
- `past_sessions\<id>\` — the kept transcript, saved and generated notes and the name label under a per-entry key, written and verified before the session key goes (`past_sessions.py`); settings in `config\past_sessions.json` ("Until I delete them" or "7 years"). Since 0.3.0 a recording kept under the patient's written development consent adds `audio.enc` + `audio-key.enc` (its key wrapped by the entry key) until deleted; `past_sessions\exports.enc` + `exports-key.dpapi` is the export ledger (outside every entry); the setting is `config\development.json` (off unless readable and on).
- The practitioner profile, style store and clinician config files — see the threat model and `docs/security/retention-schedule.md` (the authoritative list of what is kept and for how long).
