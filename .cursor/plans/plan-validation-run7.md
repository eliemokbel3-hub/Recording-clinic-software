### D1 — Check 4's second code is judged per JOINED RUN (decided 2026-10-25: V1 only; the budget governs the review row's count)
- **The unit.** A *joined run* is a maximal run of adjacent segments, within the caller's cut, where each pair `join(k, k+1)` holds: `k + 1 < end`; the same `speaker` label; `ends_mid_sentence(seg[k].transcript_words)` (`note.py:1760` — a trailing comma, semicolon, colon, en/em dash; a bare cut is NOT a join, the existing named residue); `segment_has_text(seg[k+1])` (a textless segment never joins, forward or backward — the `segment_hedged` precedent); and both wholly uncovered (no `(k, w)` in `covered`). New helper `note.joined_run(document, i, *, covered, end) -> range`: the maximal run CONTAINING `i` (extend left while `join(k-1, k)`, right while `join(k, k+1)`, clamped to `[0, end)`) — ONE implementation (C5). A partly covered segment, a speaker change, a textless segment or the cut breaks a run; a run that spans the cut is truncated, never dropped (pinned). `covered` comes from `note.covered_words(note, document)` — moved from `note_check._covered_words` with `_resolved_coords` and `_words_for_coords`, re-exported by `note_check` for its five call sites and `validation.py`'s three.
