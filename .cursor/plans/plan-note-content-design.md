## Planned Workflow Summary
### Flow 1 — A prose note in the clinical register
- The clinician finalises the note; the Note tab's prose stage asks the model for each section with the confirmed lines, then the per-section Shorthand line (only the entries whose phrases occur) and "Speaker: patient-spoken" where a patient line is present. The model writes "Pt reports LBP 3/52, worse on sitting." Check 5 folds both sides through the register, finds every fact present, no added word beyond the connectives, the frame and the folded terms, the same negations, the same protected tokens, and passes. The section shows the prose; Copy and the Cliniko write carry it as today. A section whose prose used a term not in the list keeps Clean clinical with the `style_fallback` warning, as today. There is no switch: the register is part of the two prose styles; Clean clinical, the default, stays prose-free.

### Flow 2 — A left-out line suggested, added, cleared
- The clean note shows at once; the first prose rendering lands (or none was asked for); then "Suggesting sections for 7 left-out lines…" appears under the note. A minute or two later the chooser's list re-marks three lines `[suggested: History of presenting complaint]`, the count line reads "3 lines have a suggested section (0 not assessed)", and "Show flagged or suggested lines only" lists them. Choosing one pre-selects its section in the combo; Add adds the line exactly as any hand-add does; its `clinician_line_omitted` or omission warning (class W) clears because the words are now covered, or a class-U line simply enters the note; the cue learner considers the line as it would any add. The new prose rendering for the changed section runs as soon as the suggestion job yields at its next window boundary; Save never waited on a pending suggestion; a line the clinician leaves is simply not added. Complete or Discard while a window is running returns at once — the job is aborted, its remaining windows never run, and the in-flight window finishes unseen (closing the app inside that window shows the existing "work in progress" guard for at most that window).

### Flow 3 — Measuring before shipping
- Phase R: the fixture notes (now holding a confirmed clinician) under the real model with prompt v3 and the register, both styles, against 0.2's v2 numbers; the 50 under `--prose` with the register, its Prose p/f/e counts against the v2 baseline; the practitioner's sheet. Phase C: `--suggestions confirm-all` over the 50 and the seen held-out sets, the W / U / dropped / not-assessed / wrongly-present / seconds columns, then predictions v6, rule v6, the blind `heldout-6`, run 9 at the run-of-record commit (practitioner-run, reports decoded from UTF-16), the pilot's P.5 decided again, the `h6-` cases written.

## Design Decisions
- **D1 — The lexicon is a shipped, ratified, class-typed file, durations as plain entries, refused at import on every protected-class, connective, plain-word and filler overlap, changed only with a prompt-version bump.** `config_defaults/clinical_equivalents.json` (schema 1): one entry per MEANING — `term` (one case-preserving token, compared folded), `phrases` (1–4 tokens each, already in `content_tokens` form, validated as `ExpectedFact._tokens_are_normalised` does), `class` ∈ {anatomy, symptom, measure, side_neutral, duration}. Durations are twelve ordinary entries, `{"term": "3/52", "phrases": ["three weeks", "3 weeks"], "class": "duration"}` for n = 1..12 (beyond twelve weeks is months, excluded); the `duration` class alone is exempt from the number / date invariant; no cardinal table, no composition code. Loaded in `note_config.py` beside `CLINICAL_ABBREVIATIONS` through a sibling of `_parse_shipped_vocabulary` as `CLINICAL_EQUIVALENTS`, under the same broken-install refusals. Import-time invariants, each a `RuntimeError`, in TWO homes (codex PR-MED-005: `note_check` imports `note_config` at `:273`, so the classifiers cannot be read back during config loading): the STRUCTURAL ones in `note_config` beside `_refuse_vocabulary_overlap` — schema and classes, 1:1 by meaning (a phrase in exactly one entry, a term in exactly one, a phrase never another entry's term, no phrase a prefix of another entry's phrase — longest match is then unambiguous), no term folds to a connective, no one-word phrase is a connective, `patient` or `pain`, no term equals a shipped abbreviation of a different meaning (`L`, `R`); the SEMANTIC ones at `note_check` import right after its classifiers exist (beside `_POLARITY_BEARING_TOKENS`, the pattern of the existing `:184-185` refusal) — no phrase token or term is a polarity token, a polarity-bearing word, a laterality token, a medication, or (outside `duration`) a number or date; **no term's folded form is an ORDINARY WORD**: a pinned refusal set holding the function words (as, us, is, it, at, so, to, be, do, by, me, my, an, am, or, we, he, no, ok, in, on, up, off, out, …), every shipped abbreviation whose folded form is an everyday word (`AS`, `US`, `SOB`, `MET`, `Post`, `Traps` — found 2026-11-08; Task 0.1's ratification audit walks EVERY proposed term and extends the set), `_FILLER_TOKENS` and the connectives — because the fold is symmetric, such a term would let a clinical expansion pass rule (b) over an everyday use of the word (Risk HIGH 2026-11-08; codex PR-HIGH-001); the exclusion list (degree / quality / sensation words: sore, ache, tight, stiff, dull, sharp, numb, swelling) and the ordinary-word set pinned EXACTLY in a test, like `patient` / `pain`, with a regression case per found abbreviation. The class rule the practitioner ratifies at 0.1: a term is admitted only when phrase and term name the same concept BY DEFINITION (an abbreviation and its expansion; a lay and a clinical NAME); the practitioner's own abbreviations enter this list (their app). Why: the connective allow-list is the precedent — an enforcing control shipped as package data, narrowed routinely, widened only by the practitioner; a class-typed file lets the invariants refuse CLASSES rather than spellings (`docs/lessons.md`). Rejected: a free synonym list (where invention creeps in — "sore" → "pain"); entries inside the sealed style profile (its shorthand has no phrase side); a generative duration class with a cardinal table (the harness already canonicalises spelled numbers its own way; twelve entries are data, pinned like every other entry); an editable practitioner layer now (Deferred); render-time substitution in Clean (the note-learning plan's exclusion).
