# Author notes — held-out set 3

All names, people and conversations are invented. Line numbers are 0-based. Encoding choices that apply across the set: negative scripts for the next-patient boundary (no `next_patient` role) are still tagged `end_and_new_patient`, because that is the axis they test. Scripts where a speaker fixes what they just said are tagged `contradictory`. When a line is fixed, only the fixed version is listed as a fact; the wrong version is not listed at all, so it is neither present nor absent.
